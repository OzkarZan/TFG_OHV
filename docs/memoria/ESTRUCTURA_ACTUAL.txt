╔════════════════════════════════════════════════════════════════════════════════╗
║                   FLUJOS PRINCIPALES DE DATOS                                  ║
╚════════════════════════════════════════════════════════════════════════════════╝

1. LOGIN & REGISTRO
   index.html → api-index.js → AuthController → Usuario Model → MySQL
                    ↓
                   JWT/Session

2. RESERVAR CITA (WEB)
   index.html → api-citas.js → CitaController → Cita Model → MySQL
                    ↓
                MailHelper → SMTP → Email Cliente

3. RESERVAR CITA (CHATBOT)
   Botpress → Webhook → BotpressWebhookController → CitaController
                    ↓
                MySQL + MailHelper

4. VER ESTADO (CHATBOT)
   Botpress → check_coche action → BotpressWebhookController
                    ↓
         ReparacionController → MySQL → JSON Response

5. DASHBOARD ADMIN
   dashboard.html → api-dashboard.js → MiAreaController
                    ↓
         Controllers (CRUD) → Models → MySQL

Servicios en docker-compose.yml:

  1. db (MySQL 8.0)
     • Imagen: mysql:8.0
     • Puerto: 3306
     • Volumen: db_data

  2. mailhog (Email Dev)
     • Imagen: mailhog/mailhog:latest
     • Puerto: 8025 (Web UI)
     • SMTP: puerto 1025

  3. backend (PHP + Apache)
     • Build: ./Dockerfile
     • Puerto: 8000
     • Volumen: ./backend

  4. frontend (Nginx)
     • Imagen: nginx:alpine
     • Puerto: 8080
     • Volumen: ./frontend

Dependencies:
  • backend depende de: db, mailhog
  • frontend es independiente
